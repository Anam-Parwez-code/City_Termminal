Executive Summary

City Terminal is a multi-surface platform built under the Dubai Future Foundation (DFF) 10X phase, designed to extend the airport check-in experience beyond the terminal — enabling passengers to complete identity verification, schedule curb-side pickup slots, track dedicated vehicles in real time, and receive a digital boarding pass–style confirmation before reaching Dubai International Airport (DXB).

Vision

Reduce terminal congestion and waiting time by shifting verification and logistics to a coordinated “City Terminal” network with live operations visibility.

Delivery Status

Working prototype across passenger mobile app, driver app, operations admin dashboard, Node.js API, PostgreSQL (Supabase), and bilingual AI chat service (JAIS + OpenAI).

Key outcomes demonstrated

  • Passenger app (React Native / Expo) — 20+ screens including a two-stage QR model: Luggage / Baggage Receipt QR unlocks when the driver verifies pickup; Digital Boarding Pass QR unlocks only after the vehicle reaches the airport terminal.
  • Driver app — Supabase-authenticated portal: accept bookings, trip status (Accepted → Picked up → Verified → Done), real-time dispatch sync.
  • Admin operations dashboard (React + Vite) — Live stats, dispatch map, passenger search, analytics, terminal arrival alerts with audio cue.
  • Backend API (Express 5 + Socket.IO) — Bookings, passport scan, slots, OTP pickup proof, driver tasks, confirmation flows.
  • AI service (FastAPI) — Bilingual chat (English / Arabic), RAG over booking data, JAIS LLM integration, passport OCR endpoint.

Dual QR Journey — Luggage vs Boarding Pass

City Terminal deliberately separates identity documents into two QR phases so passengers always know whether their bag is with the driver or already at the airport terminal — and so airport staff see the correct credential at each gate.

Phase 1 · After driver verification

Luggage / Baggage Receipt QR

  • Triggered when driver confirms pickup (vehicle_verified = true, status barcode_issued)
  • Backend issues JSON payload: type: baggage_receipt, documentType: Baggage Receipt
  • Socket.IO pushes status_update with vehicleVerified: true — no app refresh needed
  • Passenger sees QR on Live Tracking, My Profile, and Barcode screens
  • Encodes booking ID, vehicle, driver, flight, destination — bag status: With driver
Driver taps “Verified” → Passenger gets Luggage QR
Phase 2 · After airport terminal reached

Digital Boarding Pass QR

  • Triggered when trip status becomes at_airport (reached_airport = true)
  • Backend re-issues payload: type: digital_boarding_pass, documentType: Digital Boarding Pass
  • Passenger navigates to Confirmation screen (or Home shortcut if already at airport)
  • Full-screen boarding-style card with scannable QR via react-native-qrcode-svg
  • Same booking reference upgrades visually — bag status: At terminal
Driver marks airport arrival → Boarding Pass QR unlocks

Future Roadmap — 10X Scale-Up

The current prototype establishes the full journey skeleton. The following integrations are planned for production alignment with UAE government digital services and airline operations.

1

UAE Passport Verification API (ICP / Official Channels)

Replace and augment OCR-only verification with authoritative identity validation through the UAE federal digital identity ecosystem (e.g. ICP Emirates ID / passport validation services). Flow: capture MRZ → submit tokenized request → receive verified status, nationality, and document authenticity without storing raw biometrics on device. Reduces fraud and manual correction on Verification screen.

2

Smart Luggage — Overweight Detection via Camera

Passenger photographs checked bag before pickup. Computer vision model estimates dimensions/volume class and flags likely overweight or oversized items against airline allowance rules (weight tiers per airline_code in booking). Early warning: “Estimated 24 kg — Emirates allowance 23 kg” with option to repack or pay excess before vehicle dispatch. Reduces surprises at curb and airport belt.

3

Flight Delay & Disruption Notifications

Integrate flight status feeds (airline APIs / OAG-style data). On delay or gate change: push notification + in-app banner; auto-suggest rescheduled pickup slot; notify assigned driver and operations dashboard. Socket event flight_update propagates to passenger Live Tracking and dispatch map.

4

DXB & Airline System Integration

Boarding pass sync, bag tag pre-registration, and terminal-specific routing (T1/T2/T3) based on airline master data.

5

Predictive Dispatch & Fleet Optimization

ML on historical slot_bookings + traffic: dynamic vehicle allocation, ETA confidence intervals, SLA dashboards for DFF operations.

UAE Passport API Luggage CV Push notifications Flight status API Apple / Google Wallet pass ePayments for excess baggage

Data, Security & Compliance Considerations

  • Passport images transmitted as base64 over HTTPS; server-side processing only — no dummy data in production path
  • Admin routes protected by JWT middleware; role-based UI (Admin / Manager)
  • Driver authentication via Supabase with session isolation per device
  • PII minimization roadmap: tokenized passport references post-UAE API integration
  • Audit trail: booking status transitions, slot_bookings timestamps, vehicle_tracking coordinates
  • Alignment with UAE data residency requirements for production deployment on approved cloud regions
